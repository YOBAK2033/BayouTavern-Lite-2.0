# BayouTavern Lite 2.0

本地优先的 AI 角色互动与剧情游玩工具。作者：Yobak（B站 Bayou_x264）。

**[在线打开网页版](https://yobak2033.github.io/BayouTavern-Lite-2.0/) · [下载单文件 HTML / Android APK](https://github.com/YOBAK2033/BayouTavern-Lite-2.0/releases/latest)**

当前版本：**2.0.11**。本仓库为 2.0 独立发布仓库，保留旧仓库与历史版本。

## 开始游玩

1. 在线打开网页，或下载 HTML 后用现代浏览器打开；Android 8.0 及以上可安装 APK，桌面名称为 **BTavern Lite**。
2. 在「设置 → API配置」添加自己的兼容 API 地址、密钥和模型。模型服务由用户自行选择；需要联网及服务商额度。
3. 在「卡包」导入兼容的角色卡。正式安装包不附带测试角色、样卡或演示对话。
4. 回到「消息」新建对话，选择角色卡与开场选项，即可开始游玩。是否显示地图、背包、战斗等组件取决于角色卡配置。
5. 通过「收藏记录」「记忆列表」「参数配置」管理游玩内容。长期记忆与上下文默认自动适配，拖动参数进入自定义，恢复默认重新开启自动适配。

## 玩法说明

| 玩法 | 游玩方式 |
| --- | --- |
| 陪伴私聊 | 与单个角色聊天，可按角色卡使用表情、媒体和主动消息。 |
| 拟真群聊 | 多角色参与同一段对话，在输入框键入 @ 选择角色或所有人。 |
| 剧情玩法 | 依据角色卡中的剧情路线、世界书与开场设定推动叙事。 |
| 开放世界 | 自由探索地点，使用人物与队伍、地图、图鉴、背包等已启用组件。 |
| 竞赛玩法 | 使用作者启用的竞赛内核与规则进行对局和互动。 |
| 类宝可梦 | 使用作者启用的精灵内核，进行队伍、图鉴、形态与战斗等互动。 |

地点分组只负责整理目录；进入具体地点及部分行动会由模型融入自然叙事。抽取卡池等操作按角色卡规则在面板内结算。界面不会为未配置的玩法虚构组件。

## 文件与存档

- **网页**：资料保存在当前浏览器、当前站点的本地数据库。在线页面与下载的 HTML 不共享浏览器资料；更换入口前可导出／导入游玩存档和角色卡。浏览器清理站点数据会影响本地资料。
- **Android**：默认使用应用私有资料目录；可在「设置 → 存档管理 → 存储占用 → 路径设置」迁移到自选目录。迁移先复制并校验，再切换位置，原目录保留。
- 文件选择、建文件夹、导入／导出均使用应用内文件页。首次访问新的手机目录时由 Android 授权，之后可直接浏览。Android 限制授权某些系统目录，可选择或新建普通子文件夹。
- 自定义资料库仍使用本机设备密钥。换手机或卸载前请导出标准存档／角色卡；仅复制资料库文件夹不能代替跨设备备份。
- HTML 已内置界面脚本、样式、内置表情及地图主题图片；下载后不依赖旁边的资源文件夹。AI 回复与用户自配的远程媒体仍需要相应网络服务。

## Android 更新

从 **2.0.11** 开始，启动时检查本仓库的版本清单；回到应用时若距上次检查超过 6 小时，也会检查。设置页底部的版本号可手动检查。

发现新版本后点击下载，软件核对 APK 大小、SHA-256、应用包名和签名，然后由 Android 显示安装确认。首次从本应用安装更新时，系统可能要求允许此来源安装。不会静默安装。

旧版尚未接入此发布地址，请先从 Releases 手动安装本版。保持相同签名的覆盖安装可保留资料；不要先卸载旧版。网络不可达会显示检查未完成，可稍后重试。

# BayouTavern Lite 2.0

**作者：Bayaga_x256**

BayouTavern Lite 是基于 AI 酒馆的角色卡、世界书与对话思路改编的新酒馆变体程序：保留与角色聊天、共同创作剧情的体验，并把作者设定的状态、关系、地点、背包与玩法规则接入游玩界面。Lite 负责导入角色卡和游玩，配套的 Studio 负责制作与配置角色卡。

**[在线游玩](https://yobak2033.github.io/BayouTavern-Lite-2.0/) · [下载单文件 HTML / Android APK](https://github.com/YOBAK2033/BayouTavern-Lite-2.0/releases/latest)**

当前版本：**2.0.12**。这里是独立的 2.0 发布仓库；[旧 BayouTavern-Lite 仓库](https://github.com/YOBAK2033/BayouTavern-Lite)保留经典版和历史记录。

## 与常见 AI 酒馆的关系

| 共同的使用概念 | 本程序的实现方式 |
| --- | --- |
| 角色卡、世界书、开场与多轮对话 | 导入 Studio 发布的角色卡或 Lite 本地卡，由角色设定和上下文共同参与生成。 |
| 自行连接模型 API | 用户填写服务地址、密钥和模型；主模型与记忆官可分别配置。 |
| 角色互动与剧情创作 | 在聊天之外，按作者配置显示状态栏、关系阶段、地图、队伍、物品及其他互动组件。 |
| 长对话与记忆 | 提供长期记忆、归档、上下文适配和收藏记录；可查看、编辑并手动调整参数。 |
| 自定义玩法 | Studio 将规则整理到角色卡内，Lite 按已启用的玩法运行。并非所有卡都有战斗或地图。 |

本程序有自己的卡片格式和运行规则；相似概念不等于与其他酒馆的扩展、脚本或卡片格式全部兼容。请以导入界面支持的格式为准。

## 开始游玩

1. 在线打开网页，或下载 HTML 用现代浏览器打开。Android 8.0 及以上可安装 APK，手机桌面名称为 **BTavern Lite**。
2. 在「设置 → API配置」添加自己的兼容 API 地址、密钥和模型。模型服务需要相应网络与服务商额度。
3. 在「卡包」导入角色卡。**全新网页与 APK 均为空卡包、空对话，不附带样卡、测试存档或预填模型配置**。更新不会主动清除已有用户资料。
4. 新建对话，选择角色卡与开场，开始游玩。详细操作可查看软件内「教程」。
5. 长期记忆与上下文默认自动适配；拖动参数切换到自定义，恢复默认重新启用自动适配。

## 玩法说明

| 玩法 | 游玩方式 |
| --- | --- |
| 陪伴私聊 | 与单个角色聊天，按角色卡使用表情、媒体与主动消息。 |
| 拟真群聊 | 多角色参与同一段对话，在输入框键入 @ 选择角色或所有人。 |
| 剧情玩法 | 根据剧情路线、世界书与开场设定推动叙事。 |
| 开放世界 | 探索地点，使用已启用的人物与队伍、地图、图鉴、背包等组件。 |
| 竞赛玩法 | 按作者启用的竞赛内核与规则进行对局和互动。 |
| 类宝可梦 | 按作者配置使用精灵队伍、图鉴、形态与战斗等内容。 |

地点分组用于整理目录，打开分组不会自动移动。进入具体地点及相关行动由模型融入自然叙事；抽取卡池等操作依照角色卡规则在面板内结算。

## 资料库与文件

### 网页

- 默认使用当前浏览器、当前站点的本地数据库。在线页面、其他浏览器与下载的 HTML 不会自动共享同一份资料。
- 在设置页「存储占用 → 路径设置」可查看是否支持自选文件夹。支持目录持续读写接口的浏览器可将角色卡、媒体、对话、记忆、配置与设置保存在授权目录中。接口不可用时继续使用默认存储，界面会说明限制。
- 迁移先复制并校验，再切换来源，原资料保留。清理站点数据后可重新选择原资料目录恢复；权限失效时先重新授权。请同一时间使用一个浏览器入口操作同一资料目录，避免跨浏览器同时改写。
- 自选目录包含 API 配置等个人资料，请自行保管。无论采用哪种存储，都建议定期导出标准存档。

### Android

- 默认使用应用私有资料目录；在存储占用的路径设置中可迁移到自行选择或创建的普通文件夹。迁移先复制校验，完成后切换，原目录保留。
- 存档导入、导出与目录管理使用应用内文件页；首次访问外部手机目录需要 Android 授权。
- **头像选择使用系统图片／相册选择界面**，保留其他图片位置入口和选择后的裁剪。不同 Android 版本的相册界面会有所区别。
- Android 自定义资料库仍使用本机设备密钥。换手机或卸载前请导出标准存档和角色卡；单独复制资料目录不能替代跨设备备份。

### 角色卡封面

角色卡继续使用原本的 **`.bayoucard` / `.bayoulocal`** 文件和容器结构，**不会转换成 PNG 图片文件**。新导出的角色卡可携带封面缩略图信息，签名与原有媒体结构保持兼容。

封面显示需要文件浏览器识别该格式。Android 应用内文件页，以及支持文档缩略图的系统文件选择器中的 **BTavern Lite** 文件来源，接入了缩略图读取。其他手机文件管理器、任意下载目录和相册不保证识别自定义卡片；没有缩略图信息的旧卡仍可正常导入。Windows 桌面宿主的缩略图组件随配套桌面版本维护，单独打开 HTML 无法注册系统文件类型。

HTML 已内置界面脚本、样式与内置素材，下载后无需相邻资源文件夹；模型回复及用户配置的远程媒体仍需网络。

## Android 更新

自 **2.0.11** 起，启动时检查本仓库的[版本清单](https://yobak2033.github.io/BayouTavern-Lite-2.0/release.json)；回到软件且距上次检查超过 6 小时会再次检查。点击设置页底部版本号可手动检查。

发现更新后可下载 APK。软件校验大小、SHA-256、包名、版本与签名，再交给 Android 系统确认安装。不会静默安装；首次更新可能需要允许本应用安装更新包。

较早版本需先从 Releases 手动安装。保持同一签名的覆盖安装可以保留资料，请勿先卸载旧版。网络不可达时会显示检查未完成。

**后续发布需同时维护 Release 附件与 `release.json`**：提高版本号／版本码，使用原签名构建，上传并校验附件，再更新清单中的地址、大小与 SHA-256。只上传一个 APK 而不更新清单，不会触发应用发现新版本。
